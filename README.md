# SubmitHub — Day 1 Starter (Auth end-to-end)

This is a working skeleton for Day 1 of your 4-day plan: registration, login,
JWT issuance, role-based middleware, and a React login/register/dashboard
flow that talks to the real API.

## Folders
- `server/` — Node + Express + MySQL backend
- `client/` — React + Vite + Tailwind frontend

See the setup guide in chat for exact terminal commands.
